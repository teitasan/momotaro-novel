# 桃太郎｜基準ルート

ブラウザで遊べる、桃太郎ノベルゲームの最小プロトタイプです。

## 起動方法

このフォルダで、次のコマンドを実行します。

```bash
python3 -m http.server 4173
```

ブラウザで <http://127.0.0.1:4173/> を開くと遊べます。

## 収録内容

- 正しい選択を選ぶと基準ルートを進行
- 正史から外れる選択は状態を変えず、その場に留まる
- きびだんごの残数、仲間、進行フラグを画面右側で確認
- 村、家の内部、道中、鬼ヶ島の背景画像
- 桃太郎、おじいさん、おばあさん、犬、猿、キジ、鬼の立ち絵
- きびだんごのアイテム画像

シナリオと状態遷移は `app.js`、見た目は `styles.css` にまとめています。
